# A harness is not called a coding agent

The thing `cladenc` takes in and improves is a coding harness, or an agentic coding harness. It is not called a coding agent, in conversation or in anything written.

**Why:** Coding harness and agentic coding harness name the thing `cladenc` improves. A harness is not defined as a coding agent either.

**How to apply:** Say harness, coding harness or agentic coding harness in replies, issues, commits, memories and any text the code prints. The paper's title, which has the other name in it, is a citation and stays as it is. Related: [[the-paper-is-a-starting-point]], [[cladenc-takes-a-primogenitor-and-a-model]].
