# A harness procreates only once scored on every task

A harness can be the progenitor of a procreation only once it has been scored on every task of every benchmark the directed evolution was given. Where a procreation is due and no harness has been scored on every task, an assessment is started in its place.

**Why:** It is the user's rule. To the user a harness is scored against its benchmarks, each as a whole, and a progenitor learns from all of that. That each harness that procreates takes as many assessments from `--budget` as there are tasks is known to the user and accepted. My reading, not the user's words: a harness that has been scored on part of its tasks does not count as scored yet.

**How to apply:**

- Do not propose one task, another number of tasks, or a flag that gives the number, as what a harness needs before it procreates.
- The rule is about who may procreate. Harnesses are still assessed one task at a time, and a harness that never procreates can end a directed evolution scored on only some of the tasks. Changing that is not part of the rule and is the user's to ask for.
- To the user, scored means scored on the whole of every benchmark. Where a harness scored on one task or on some tasks is meant, say first that an assessment is one harness tried on one task, and then say on how many tasks, per [[an-explanation-says-what-happens]].
