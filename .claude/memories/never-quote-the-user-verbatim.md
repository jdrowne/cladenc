# Never quote the user verbatim

Nothing the user writes is recorded word for word, anywhere: not in a memory, an issue title or body, a commit message, a comment in code, a task, a feedback draft, a summary or a compaction. Each of those carries the user's point restated in fresh words, with no quotation marks around the user's sentences and no unquoted copy of them either.

**Why:** The user does not want their own wording kept on record. A paraphrase keeps the rule and its reason; the exact wording adds nothing a later session needs.

**How to apply:** Before writing down a correction or an instruction, restate it as the rule it sets. When a **Why:** line cites something the user said, say what they held, without quoting it. A template that asks for the user's words quoted gets a paraphrase marked as one. A name the user gives, of a file, label, term or command, keeps that name; that is not a quotation of the sentence around it. Quoting a command, a file's content, a commit message or Claude's own wording is still fine.
