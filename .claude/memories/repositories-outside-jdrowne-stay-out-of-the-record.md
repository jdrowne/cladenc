# Repositories outside jdrowne stay out of the record

A repository that the jdrowne account does not own is not mentioned in a memory. Nothing from such a repository is quoted in anything public: a memory, an issue, a commit message, code or a workflow.

**Why:** This repository is public, and its memories, issues and history are read by anyone. On 2026-11-14 the user asked for every mention of a repository outside jdrowne to be taken out of the memories, and the same day pointed to a workflow in such a repository as a model for the release workflow here, on the condition that nothing at all from it be quoted in anything public. The memories had named three such repositories by then, each put there by a session and none asked for.

**How to apply:** When a rule or a reason comes from a repository outside jdrowne, state the rule and the reason on their own, with no credit to where they were seen. A sibling repository may be named when jdrowne owns it, and is then called a jdrowne repository. When the user points to a file outside jdrowne as a model, read only what was pointed to, write what is needed here afresh, and say nothing in public of where the shape came from; what was taken and what was left out is told to the user in the conversation. My own reading, not something the user said: the same care holds for the name of such a repository in issues and commit messages, not only for quotations. See [[the-work-is-clean-room]] for the code that is never read at all, and [[never-quote-the-user-verbatim]] for the user's own words.
