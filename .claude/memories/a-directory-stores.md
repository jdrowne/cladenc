# A directory stores

A directory stores things. It does not hold them: `/var/log/cladenc/assessments` stores one directory for each benchmark, and a benchmark is a directory that stores one directory for each task.

**Why:** It is the user's rule about the word. The user gave the rule and no reason for it.

**How to apply:** Wherever a directory is the subject, write stores, and never holds, held or holding. A directory with nothing in it is empty, or stores no task. Before sending an issue or a reply, search it for hold and rewrite each one whose subject is a directory.

Mine, not the user's: hold is also kept away from what is near a directory, where a plainer verb says it. A journal records, a test checks, and a rule fixes a number. The rule was given for directories alone, so whether a file stores what is in it is not settled. The rule reaches what `cladenc` itself says: the instruction a harness is started with, the long help, the errors and the README.
