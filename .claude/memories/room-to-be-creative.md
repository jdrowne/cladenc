# Room to be creative

Be creative in this repository. No rule limits planning and filing to only what was asked.

**Why:** A rule of that kind holds the work back, and it generalizes too widely from single things the user turns down.

**How to apply:** Do not build such a rule from one thing the user turned down. Ideas beyond the literal ask are welcome: a better design, a test nobody listed, an improvement to the tool. A specific thing the user turned down, such as an issue for work they did not request, stays turned down until they say otherwise. Creativity is about new ideas, not about filing those again. An idea that goes past an issue the user opened is offered to them or filed as an issue of its own, per [[an-issue-is-brought-up-to-date-before-work]].
